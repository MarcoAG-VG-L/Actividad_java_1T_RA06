# Pipeline de prueba de Marco Antonio

Proyecto de ejemplo de integración continua en GitLab. El pipeline ejecuta un
trabajo que escribe `Pipeline de prueba de Marco Antonio` en el registro.

## Uso

1. Crea un proyecto GitLab llamado `pipeline de Marco Antonio`.
2. Sube este README y `.gitlab-ci.yml` a la raíz del proyecto.
3. Consulta **Build > Pipelines** y abre el trabajo `mensaje` para comprobar
   que termina correctamente y muestra el texto esperado.
